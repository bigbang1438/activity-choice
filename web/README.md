# 一起定活动：前端

> 公开源码范围：本文保留原开发环境的实施与验证历史。提到的日志、截图、仓库外 QA/研究原始材料不在此公开目录；当前可用测试和质量限制见 [EVIDENCE 摘要](../EVIDENCE.md)。


普通朋友一起比较活动候选、表达偏好，组织者确定主备与集合安排，分享一份可撤销的只读定案。

## 启动

```powershell
npm ci
npm run dev
```

开发入口 `http://127.0.0.1:5198`，`/api` 代理至本机 Java 服务 `8098`。`npm run build` 生成 `dist/`；由统一打包流程复制至 Java 静态资源目录。后端需将 `/`、`/join`、`/share/{id}` 转发 `index.html`，从链接直达和刷新仍能打开。

## 正常流程

1. 在登录页创建自己的账号；没有固定演示账号。
2. 新建活动，添加两个或更多结构化候选。开放、费用、预约分别标记核实状态；已核实必须附来源与核实日期。
3. 组织者生成一次性邀请，将完整链接交给一位朋友。朋友登录自己的账号，点击“加入活动”领取。组织者可以撤销未使用邀请。
4. 各成员分别表达“想去 / 可接受 / 不想去”，可以改选或撤回。每个候选列出未回应的人。
5. 组织者保存不同的主选和备选，填写集合时间、集合地点、公开提醒。若活动发生并发变更，409 后刷新最新内容，必须重新查看并确认，不自动重提旧定案。
6. 发布只读定案。新发布形成独立版本，旧链接提示旧版；撤销后原链接不显示活动正文。

## 设计与隐私

白底、海蓝和明黄票签，候选与集合安排优先。公开页在 375 px 单列直接阅读，不依赖画布或横向拖拽。未知费用不会被写为免费，未知预约不会被写成无需预约。

所有文本使用 Vue 文本绑定；公开页只访问公开 publication API 并明确渲染公开字段，没有读取整个私有活动对象。成员备注只在成员界面展示。会话由 HttpOnly Cookie 管理，前端不保存密码、会话令牌或 CSRF 到本地存储；登录/注册后重新读取旋转后的 CSRF。

## 验证

```powershell
npm test
npm run build
```

仓库内 `tests/behavior.test.mjs` 共 6 项，覆盖未知规则、逐候选未回应、定案冲突不自动重提、公开链接撤销清正文、权限错误不假报成功及邀请链接解析。原开发环境另做隔离浏览器会话与 375 px 页面检查，具体流程和范围见 [EVIDENCE 摘要](../EVIDENCE.md)。

公开源码目录没有附上原 QA 辅助脚本、日志、账号数据和截图，因此不提供指向缺失脚本的运行命令。没有把这些本机验收当作真实用户试用。

## 当前局限

- 不含短信、邮件、地图搜索、订票或支付。来源由成员手工填写，出发前仍需检查官方最新说明。
- 界面不自动轮询，点击“刷新回应”更新；保存定案由服务端版本校验防止覆盖未读变化。
- 只有本页刚生成的邀请能再次显示原始链接；刷新后不恢复 token。页面已说明一次性和有效期，后端只存摘要，避免将 token 持久保存到前端。需要找回历史未使用邀请的管理能力尚未实现。
- 按账号记录偏好，不能证明真实身份或阻止一人注册多个账号；投票不自动代表所有人达成共识。
- 这是本机作品，尚无真实参与者试用与业务收益数据。
